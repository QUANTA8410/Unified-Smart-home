# Unified Home System (UHS) 🏡✨

> **A Production-Grade, Local-First Smart Home Platform combining Google Home Material 3 UI/UX, Apple visionOS / iOS 26 Liquid Glass Design System, Deep Appliance Granularity (LG ThinQ, Samsung SmartThings), Direct LAN Hardware Drivers, an Always-On 24/7 Android Node Server, and 3D Spatial Digital Twin.**

## 🌟 Key Features

### 1. 💎 Apple visionOS / iOS 26 Liquid Glass Design System
- **Titanium Depth Canvas**: High-end deep space gradient backdrop with floating, animated ambient light refraction orbs blurred with hardware `ImageFiltered` gaussian shaders.
- **Specular Glass Containers**: Custom `_AppleSpecularBorderPainter` rendering physical-light rim highlights, frosted backdrops, and haptic interactive response.
- **Expanding Dock Pills & Cockpits**: Tactile bottom dock, active hub telemetry pills, and dynamic floating status badges.

### 2. ⚡ Zero Dummy Fallbacks — 100% Real Hardware IoT
- **Samsung SmartThings Cloud**: Full Bearer PAT discovery querying `GET https://api.smartthings.com/v1/devices`. Manages real 36-character UUID devices, reads live telemetry via `GET /devices/{id}/status`, and sends commands via `POST /devices/{id}/commands`.
- **Universal Home Assistant / Matter Hub Bridge**: Connects to any local Home Assistant or Matter bridge (`http://IP:8123` + long-lived bearer token) to import and control appliances across ecosystems.
- **Direct Local Tuya LAN Driver**: AES-128-ECB encrypted frame communication over TCP port `6668` with 16-character `localKey` pairing for Wipro Smart Bulbs and Tuya smart plugs.
- **Direct DIAL/UPnP HTTP TV Protocol**: Controls OnePlus 4K Smart TVs directly over local HTTP port `8008`.
- **Hardware-Accelerated RTSP/ONVIF Camera Streamer**: Low-latency video decoder (`media_kit` + `libmpv`) embedded in an interactive 16:9 Viewfinder with 360° PTZ gimbal joystick controls (pan/tilt angle tracking), night vision, AI motion tracking, and privacy masking.
- **Out-of-App Handoff & Auto-Return Discovery**:
  - **Realme Link** (`com.realme.link`): Native 1-tap app launch with active lifecycle return watcher and RTSP/ONVIF port sweep (`554`, `8554`, `8000`).
  - **Philips Home Safety & Access**: Multi-package priority launcher (`com.philips.homesafety`, `com.philips.homeaccess`, `com.philips.homesafety.app`, `com.philips.cl.homeaccess`) with automatic Play Store fallback, subnet probing (`554`, `8554`, `80`, `8080`), and 1-tap live feed pairing.

### 3. 🌐 24/7 Always-On Android Home Node Server Mode
- Turns any old or spare Android phone into a permanent, 24/7 edge smart home server running on local port `8765`.
- **Native Android CPU WakeLock & High-Performance WifiLock**: `PowerManager.PARTIAL_WAKE_LOCK` (`"UnifiedHome::NodeWakeLock"`) and `WifiManager.WIFI_MODE_FULL_HIGH_PERF` prevent CPU and Wi-Fi radios from sleeping.
- **Battery Optimization Exemption**: Direct native prompt for `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`.
- **REST API & Real-Time WebSockets**:
  - `GET /` — Standalone Apple Liquid Glass HTML5 Web Dashboard.
  - `GET /api/status` — Live hub telemetry (uptime, connected clients, device count, server metrics).
  - `GET /api/devices` & `POST /api/devices/{id}/control` — Universal REST control endpoints.
  - `GET /api/logs` — Live hub event logs.
  - `WS /ws` — Bidirectional real-time WebSocket state streaming.
- **AMOLED Burn-In Clock Mode**: Floating, moving clock and low-power standby mode for prolonged screen life.

### 4. 🗺️ 3D Spatial Digital Twin Map View
- Interactive 3D spatial floor plan projection with full 360° orbit (yaw & pitch) and pinch-to-zoom.
- Room ambient fills, depth-extruded elevation walls, and dynamic thermal convection vectors for cooling air circulation.
- Interactive pulsating device nodes with real-time appliance states, energy heatmaps, and quick toggles.

### 5. 🔄 Dual Over-The-Air (OTA) Update System
- **In-App Application Updates**: SemVer comparison against remote manifests, chunked HTTP streaming download with live transfer speed meter (MB/s), SHA-256 cryptographic verification, and native Android `FileProvider` package installer dispatch.
- **Device Fleet Firmware FOTA Engine**: 5-stage flashing lifecycle (`Handshake & Lock` $\to$ `Downloading Chunk` $\to$ `SHA-256 Verification` $\to$ `Non-Volatile Partition Flashing` $\to$ `Reboot & Self-Test`) supporting individual device flashing and 1-tap "Update All Devices" orchestration.

## 🛠️ Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev) (v3.29.0 or higher)
- [Android SDK](https://developer.android.com/studio) (API 24+ / Android 7.0 through Android 15)
- Java 17+ / Gradle 8+

### Setup & Run
```bash
# Clone the repository
git clone https://github.com/QUANTA8410/UHS.git
cd UHS

# Install dependencies
flutter pub get

# Run analyzer & automated tests
flutter analyze --no-pub
flutter test

# Run on connected Android device
flutter run
```

### Build Production Release APK
```bash
flutter build apk --release --tree-shake-icons
```
Output artifact: `build/app/outputs/flutter-apk/app-release.apk`

#### Install via ADB:
```bash
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

import os
import math
from PIL import Image, ImageDraw, ImageFilter

def create_unified_smart_home_icon(size=2048, is_round=False):
    # 1. Base Image
    img = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    
    # 2. Draw Deep Space Background with Radial Gradient
    bg = Image.new("RGBA", (size, size), (0, 0, 0, 255))
    bg_draw = ImageDraw.Draw(bg)
    
    cx, cy = size // 2, size // 2
    max_radius = int(size * 0.72)
    
    # Render smooth cosmic gradient
    for r in range(max_radius, 0, -8):
        t = r / max_radius
        # Interpolate between deep space black (5, 8, 18) and midnight cyan-navy (18, 30, 62)
        red = int(5 * t + 22 * (1 - t))
        green = int(8 * t + 36 * (1 - t))
        blue = int(18 * t + 78 * (1 - t))
        bg_draw.ellipse([cx - r, cy - r, cx + r, cy + r], fill=(red, green, blue, 255))
        
    # 3. Add Ambient Ecosystem Glows (Auras)
    aura = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    aura_draw = ImageDraw.Draw(aura)
    
    # Samsung Cyan Aura (Top)
    aura_draw.ellipse([cx - 450, cy - 650, cx + 450, cy + 250], fill=(0, 229, 255, 60))
    # LG Ruby Aura (Bottom Left)
    aura_draw.ellipse([cx - 650, cy - 200, cx + 150, cy + 600], fill=(255, 42, 109, 50))
    # Philips Hue Golden Ambient Glow (Center Core)
    aura_draw.ellipse([cx - 300, cy - 100, cx + 300, cy + 500], fill=(255, 180, 0, 70))
    # Matter Emerald Aura (Right)
    aura_draw.ellipse([cx + 50, cy - 150, cx + 650, cy + 450], fill=(0, 230, 118, 40))
    
    aura = aura.filter(ImageFilter.GaussianBlur(radius=110))
    bg.alpha_composite(aura)
    
    # 4. Concentric Matter / Smart Mesh Rings
    mesh_layer = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    mesh_draw = ImageDraw.Draw(mesh_layer)
    
    # Outer mesh orbit ring
    mesh_draw.ellipse([cx - 720, cy - 720, cx + 720, cy + 720], outline=(255, 255, 255, 25), width=4)
    mesh_draw.ellipse([cx - 560, cy - 560, cx + 560, cy + 560], outline=(0, 229, 255, 35), width=3)
    
    # Diagonal connection axes (45 deg)
    axis_color = (255, 255, 255, 30)
    mesh_draw.line([cx - 600, cy - 600, cx + 600, cy + 600], fill=axis_color, width=2)
    mesh_draw.line([cx - 600, cy + 600, cx + 600, cy - 600], fill=axis_color, width=2)
    
    bg.alpha_composite(mesh_layer)
    
    # 5. 3D Isometric Spatial Glass House
    house_layer = Image.new("RGBA", (size, size), (0, 0, 0, 0))
    h_draw = ImageDraw.Draw(house_layer)
    
    # Geometric Coordinates for Isometric Pavilion
    # Scale relative to 2048
    s = size / 2048.0
    
    top_v = (1024 * s, 480 * s)
    left_v = (560 * s, 750 * s)
    right_v = (1488 * s, 750 * s)
    center_v = (1024 * s, 1020 * s)
    bot_left_v = (560 * s, 1310 * s)
    bot_right_v = (1488 * s, 1310 * s)
    bot_v = (1024 * s, 1580 * s)
    
    # A. Top Facet / Roof (Samsung SmartThings Electric Cyan & Apple Spatial Glass)
    # Polygon: top_v -> right_v -> center_v -> left_v
    roof_poly = [top_v, right_v, center_v, left_v]
    h_draw.polygon(roof_poly, fill=(0, 200, 255, 210))
    
    # Internal roof gradient highlights
    for i in range(1, 30):

        p1 = (top_v[0] + (left_v[0] - top_v[0]) * factor, top_v[1] + (left_v[1] - top_v[1]) * factor)
        p2 = (top_v[0] + (right_v[0] - top_v[0]) * factor, top_v[1] + (right_v[1] - top_v[1]) * factor)
        p3 = (center_v[0] + (right_v[0] - center_v[0]) * (1 - factor), center_v[1] + (right_v[1] - center_v[1]) * (1 - factor))
        p4 = (center_v[0] + (left_v[0] - center_v[0]) * (1 - factor), center_v[1] + (left_v[1] - center_v[1]) * (1 - factor))
        
        red = int(0 + 20 * factor)

    # D. Inner Frosted Cutaway Living Room Window (Left Wall)

package com.antigravity.home.unified_home

import androidx.core.app.NotificationCompat

class MainActivity : FlutterActivity() {
    private val NOTIFICATION_CHANNEL = "com.antigravity.home/notifications"
    private val NOTIFICATION_CHANNEL_ALT = "com.antigravity.home.unified_home/notifications"
    private val OTA_CHANNEL = "com.antigravity.home.unified_home/ota"
    private val MASTER_OS_CHANNEL = "com.antigravity.home.unified_home/master_os"
    private val LIVE_CHANNEL_ID = "unified_home_live_appliance"
    private val ALERT_CHANNEL_ID = "unified_home_appliance_alerts"
    private var masterMethodChannel: MethodChannel? = null
    private var nodeWakeLock: PowerManager.WakeLock? = null
    private var nodeWifiLock: WifiManager.WifiLock? = null

    override fun configureFlutterEngine(flutterEngine: FlutterEngine) {
        super.configureFlutterEngine(flutterEngine)
        createNotificationChannels()

        // 1. Zero-Dependency Native Notification & Audible Chime Alert Bridge
        val notificationHandler = MethodChannel.MethodCallHandler { call, result ->
            when (call.method) {
                "requestPermission" -> {
                    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {
                        if (ActivityCompat.checkSelfPermission(
                                this,
                                Manifest.permission.POST_NOTIFICATIONS
                            ) != PackageManager.PERMISSION_GRANTED
                        ) {
                            ActivityCompat.requestPermissions(
                                this,
                                arrayOf(Manifest.permission.POST_NOTIFICATIONS),
                                1001
                            )
                        }
                    }
                    result.success(true)
                }
                "triggerApplianceAlert" -> {
                    val title = call.argument<String>("title") ?: "🧺 Appliance Alert"
                    val body = call.argument<String>("body") ?: "Cycle completed!"
                    val withChime = call.argument<Boolean>("withChime") ?: true
                    val withVibration = call.argument<Boolean>("withVibration") ?: true
                    val notificationId = call.argument<Int>("notificationId") ?: 1002

                    val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
                    val soundUri = RingtoneManager.getDefaultUri(RingtoneManager.TYPE_NOTIFICATION)

                    val builder = NotificationCompat.Builder(this, ALERT_CHANNEL_ID)
                        .setSmallIcon(android.R.drawable.ic_dialog_info)
                        .setContentTitle(title)
                        .setContentText(body)
                        .setPriority(NotificationCompat.PRIORITY_HIGH)
                        .setAutoCancel(true)

                    if (withChime) {
                        builder.setSound(soundUri)
                        try {
                            val ringtone = RingtoneManager.getRingtone(applicationContext, soundUri)
                            ringtone?.play()
                        } catch (_: Exception) {}
                    }

                    if (withVibration) {
                        builder.setVibrate(longArrayOf(0, 300, 200, 300))
                        try {
                            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
                                val vibrator = getSystemService(Context.VIBRATOR_SERVICE) as? Vibrator
                                vibrator?.vibrate(
                                    VibrationEffect.createWaveform(longArrayOf(0, 300, 200, 300), -1)
                                )
                            } else {
                                @Suppress("DEPRECATION")
                                val vibrator = getSystemService(Context.VIBRATOR_SERVICE) as? Vibrator
                                vibrator?.vibrate(longArrayOf(0, 300, 200, 300), -1)
                            }
                        } catch (_: Exception) {}
                    }

                    manager.notify(notificationId, builder.build())
                    result.success(true)
                }
                "enableNodeKeepAlive" -> {
                    try {
                        if (nodeWakeLock == null) {
                            val powerManager = getSystemService(Context.POWER_SERVICE) as PowerManager
                            nodeWakeLock = powerManager.newWakeLock(
                                PowerManager.PARTIAL_WAKE_LOCK,
                                "UnifiedHome::NodeWakeLock"
                            ).apply {
                                setReferenceCounted(false)
                            }
                        }
                        if (nodeWakeLock?.isHeld != true) {
                            nodeWakeLock?.acquire(24 * 60 * 60 * 1000L)
                        }

                        if (nodeWifiLock == null) {
                            val wifiManager = applicationContext.getSystemService(Context.WIFI_SERVICE) as WifiManager
                            val wifiMode = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.Q) {
                                WifiManager.WIFI_MODE_FULL_LOW_LATENCY
                            } else {
                                @Suppress("DEPRECATION")
                                WifiManager.WIFI_MODE_FULL_HIGH_PERF
                            }
                            nodeWifiLock = wifiManager.createWifiLock(wifiMode, "UnifiedHome::NodeWifiLock").apply {
                                setReferenceCounted(false)
                            }
                        }
                        if (nodeWifiLock?.isHeld != true) {
                            nodeWifiLock?.acquire()
                        }

                        window.addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)

                        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
                            val powerManager = getSystemService(Context.POWER_SERVICE) as PowerManager
                            if (!powerManager.isIgnoringBatteryOptimizations(packageName)) {
                                val intent = Intent(Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS).apply {
                                    data = Uri.parse("package:$packageName")
                                    flags = Intent.FLAG_ACTIVITY_NEW_TASK
                                }
                                startActivity(intent)
                            }
                        }
                        result.success(true)
                    } catch (e: Exception) {
                        result.error("KEEP_ALIVE_ERROR", e.localizedMessage, e.message)
                    }
                }
                "disableNodeKeepAlive" -> {
                    try {
                        if (nodeWakeLock?.isHeld == true) {
                            nodeWakeLock?.release()
                        }
                    } catch (_: Exception) {}

                    try {
                        if (nodeWifiLock?.isHeld == true) {
                            nodeWifiLock?.release()
                        }
                    } catch (_: Exception) {}

                    window.clearFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON)
                    result.success(true)
                }
                "getNodeKeepAliveStatus" -> {
                    val isWake = nodeWakeLock?.isHeld == true
                    val isWifi = nodeWifiLock?.isHeld == true
                    var isBatteryIgnored = false
                    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
                        val powerManager = getSystemService(Context.POWER_SERVICE) as PowerManager
                        isBatteryIgnored = powerManager.isIgnoringBatteryOptimizations(packageName)
                    }
                    result.success(
                        mapOf(
                            "wakeLock" to isWake,
                            "wifiLock" to isWifi,
                            "batteryOptimizationIgnored" to isBatteryIgnored
                        )
                    )
                }
                "launchExternalApp" -> {
                    val pkg = call.argument<String>("packageName") ?: ""
                    val launchIntent = packageManager.getLaunchIntentForPackage(pkg)
                    if (launchIntent != null) {
                        launchIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
                        startActivity(launchIntent)
                        result.success(true)
                    } else {
                        result.success(false)
                    }
                }
                "launchFirstInstalledApp" -> {
                    val packages = call.argument<List<String>>("packages") ?: listOf()
                    var launched = false
                    for (pkg in packages) {
                        val launchIntent = packageManager.getLaunchIntentForPackage(pkg)
                        if (launchIntent != null) {
                            launchIntent.addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)
                            startActivity(launchIntent)
                            launched = true
                            break
                        }
                    }
                    result.success(launched)
                }
                else -> result.notImplemented()
            }
        }

        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, NOTIFICATION_CHANNEL)
            .setMethodCallHandler(notificationHandler)
        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, NOTIFICATION_CHANNEL_ALT)
            .setMethodCallHandler(notificationHandler)

        // 2. OTA Update Channel
        MethodChannel(flutterEngine.dartExecutor.binaryMessenger, OTA_CHANNEL).setMethodCallHandler { call, result ->
            if (call.method == "installApk") {
                val filePath = call.argument<String>("filePath")
                if (filePath == null) {
                    result.error("INVALID_PATH", "File path is null", null)
                    return@setMethodCallHandler
                }
                val file = File(filePath)
                if (!file.exists()) {
                    result.error("FILE_NOT_FOUND", "APK file does not exist at $filePath", null)
                    return@setMethodCallHandler
                }

                try {
                    val intent = Intent(Intent.ACTION_VIEW).apply {
                        flags = Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_GRANT_READ_URI_PERMISSION
                        val uri = FileProvider.getUriForFile(
                            context,
                            "${context.packageName}.fileprovider",
                            file
                        )
                        setDataAndType(uri, "application/vnd.android.package-archive")
                    }
                    context.startActivity(intent)
                    result.success(true)
                } catch (e: Exception) {
                    result.error("INSTALL_ERROR", e.localizedMessage, e.message)
                }
            } else {
                result.notImplemented()
            }
        }

        // 3. Master OS Channel (Live Notifications & Deep-Link forwarding)
        masterMethodChannel = MethodChannel(flutterEngine.dartExecutor.binaryMessenger, MASTER_OS_CHANNEL)
        masterMethodChannel?.setMethodCallHandler { call, result ->
            when (call.method) {
                "updateLiveNotification" -> {
                    val title = call.argument<String>("title") ?: "Appliance Active"
                    val subtitle = call.argument<String>("subtitle") ?: "Running..."
                    val progress = call.argument<Int>("progress") ?: 50
                    showOngoingNotification(title, subtitle, progress)
                    result.success(true)
                }
                "dismissLiveNotification" -> {
                    val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
                    manager.cancel(9001)
                    result.success(true)
                }
                else -> result.notImplemented()
            }
        }
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        handleIncomingIntent(intent)
    }

    override fun onNewIntent(intent: Intent) {
        super.onNewIntent(intent)
        handleIncomingIntent(intent)
    }

    private fun handleIncomingIntent(intent: Intent?) {
        val data = intent?.dataString
        if (!data.isNullOrEmpty()) {
            masterMethodChannel?.invokeMethod("onDeepLink", data)
        }
    }

    private fun showOngoingNotification(title: String, subtitle: String, progress: Int) {
        val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
        val builder = NotificationCompat.Builder(this, LIVE_CHANNEL_ID)
            .setSmallIcon(android.R.drawable.ic_dialog_info)
            .setContentTitle(title)
            .setContentText(subtitle)
            .setOngoing(true)
            .setOnlyAlertOnce(true)
            .setProgress(100, progress, false)
            .setPriority(NotificationCompat.PRIORITY_LOW)
        manager.notify(9001, builder.build())
    }

    private fun createNotificationChannels() {
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
            val manager = getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager

            // Live progress channel (Low importance for ongoing persistent state)
            val liveChannel = NotificationChannel(
                LIVE_CHANNEL_ID,
                "Live Appliance Progress",
                NotificationManager.IMPORTANCE_LOW
            )
            manager.createNotificationChannel(liveChannel)

            // High importance alert channel with audible chime and vibration
            val soundUri = RingtoneManager.getDefaultUri(RingtoneManager.TYPE_NOTIFICATION)
            val audioAttributes = AudioAttributes.Builder()
                .setContentType(AudioAttributes.CONTENT_TYPE_SONIFICATION)
                .setUsage(AudioAttributes.USAGE_NOTIFICATION)
                .build()

            val alertChannel = NotificationChannel(
                ALERT_CHANNEL_ID,
                "Appliance & Automation Alerts",
                NotificationManager.IMPORTANCE_HIGH
            ).apply {
                description = "Audible chimes and heads-up alerts when smart appliances finish cycles"
                enableLights(true)
                enableVibration(true)
                vibrationPattern = longArrayOf(0, 300, 200, 300)
                setSound(soundUri, audioAttributes)
            }
            manager.createNotificationChannel(alertChannel)
        }
    }

    override fun onDestroy() {
        try {
            if (nodeWakeLock?.isHeld == true) {
                nodeWakeLock?.release()
            }
        } catch (_: Exception) {}
        try {
            if (nodeWifiLock?.isHeld == true) {
                nodeWifiLock?.release()
            }
        } catch (_: Exception) {}
        super.onDestroy()
    }

/// Architectural floor material types matching House Control Three.js procedural floors.
enum FloorMaterialType {
  oak,
  walnut,
  tile,
  stone;

  Color get color {
    switch (this) {
      case FloorMaterialType.oak:
        return const Color(0xFFC7A47C); // Warm oak wood planks
      case FloorMaterialType.walnut:
        return const Color(0xFF94705A); // Deep walnut parquet planks
      case FloorMaterialType.tile:
        return const Color(0xFFD5DADE); // Architectural ceramic tile
      case FloorMaterialType.stone:
        return const Color(0xFFA2A7AE); // Slate stone tile
    }
  }

  Color get groutColor {
    switch (this) {
      case FloorMaterialType.oak:
        return const Color(0x33281A10);
      case FloorMaterialType.walnut:
        return const Color(0x331B120B);
      case FloorMaterialType.tile:
        return const Color(0xFFAAB0B8);
      case FloorMaterialType.stone:
        return const Color(0xFF7C828B);
    }
  }

  static FloorMaterialType fromString(String? val) {
    switch (val?.toLowerCase()) {
      case 'walnut':
        return FloorMaterialType.walnut;
      case 'tile':
        return FloorMaterialType.tile;
      case 'stone':
        return FloorMaterialType.stone;
      case 'oak':
      default:
        return FloorMaterialType.oak;
    }
  }
}

/// Represents an architectural opening in a wall (door, window, open archway).
class Opening3D {
  final String type; // 'door', 'window', 'open'
  final Offset from;
  final Offset to;
  final double sill;
  final double head;

  const Opening3D({
    required this.type,
    required this.from,
    required this.to,
    this.sill = 0.0,
    this.head = 2.2,
  });

  Map<String, dynamic> toJson() => {
        'type': type,
        'from': [from.dx, from.dy],
        'to': [to.dx, to.dy],
        'sill': sill,
        'head': head,
      };

  factory Opening3D.fromJson(Map<String, dynamic> json) {
    final fromList = (json['from'] as List?)?.map((e) => (e as num).toDouble()).toList() ?? [0.0, 0.0];
    final toList = (json['to'] as List?)?.map((e) => (e as num).toDouble()).toList() ?? [0.0, 0.0];
    return Opening3D(
      type: json['type'] as String? ?? 'door',
      from: Offset(fromList[0], fromList[1]),
      to: Offset(toList[0], toList[1]),
      sill: (json['sill'] as num?)?.toDouble() ?? 0.0,
      head: (json['head'] as num?)?.toDouble() ?? 2.2,
    );
  }

/// Represents a distinct room zone within the 3D isometric house.
class Room3DZone {
  final String id;
  final String name;
  final Rect gridRect; // Normalized 0.0..1.0 house footprint coordinates
  final Color floorColor;
  final FloorMaterialType floorType;
  final double cameraZoom; // e.g. 1.85 for room focus, 1.0 for entire house
  final Offset cameraFocus; // Normalized 0.0..1.0 center of focus

  const Room3DZone({
    required this.id,
    required this.name,
    required this.gridRect,
    required this.floorColor,
    this.floorType = FloorMaterialType.oak,
    this.cameraZoom = 1.85,
    required this.cameraFocus,
  });

  Map<String, dynamic> toJson() => {
        'id': id,
        'name': name,
        'rect': [gridRect.left, gridRect.top, gridRect.width, gridRect.height],
        'color': floorColor.toARGB32(),
        'floor': floorType.name,
        'cameraZoom': cameraZoom,
        'cameraFocus': [cameraFocus.dx, cameraFocus.dy],
      };

  factory Room3DZone.fromJson(Map<String, dynamic> json) {
    final rectList = (json['rect'] as List?)?.map((e) => (e as num).toDouble()).toList() ??
        [0.0, 0.0, 0.5, 0.5];
    final focusList = (json['cameraFocus'] as List?)?.map((e) => (e as num).toDouble()).toList() ??
        [0.25, 0.25];
    final floorType = FloorMaterialType.fromString(json['floor'] as String?);

    return Room3DZone(
      id: json['id'] as String? ?? 'living',
      name: json['name'] as String? ?? 'Living',
      gridRect: Rect.fromLTWH(rectList[0], rectList[1], rectList[2], rectList[3]),
      floorColor: json['color'] != null ? Color(json['color'] as int) : floorType.color,
      floorType: floorType,
      cameraZoom: (json['cameraZoom'] as num?)?.toDouble() ?? 1.85,
      cameraFocus: Offset(focusList[0], focusList[1]),
    );
  }

  Room3DZone copyWith({
    String? id,
    String? name,
    Rect? gridRect,
    Color? floorColor,
    FloorMaterialType? floorType,
    double? cameraZoom,
    Offset? cameraFocus,
  }) {
    return Room3DZone(
      id: id ?? this.id,
      name: name ?? this.name,
      gridRect: gridRect ?? this.gridRect,
      floorColor: floorColor ?? this.floorColor,
      floorType: floorType ?? this.floorType,
      cameraZoom: cameraZoom ?? this.cameraZoom,
      cameraFocus: cameraFocus ?? this.cameraFocus,
    );
  }
}

  factory House3DTwinLayout.fromJson(Map<String, dynamic> json) {
    final rawRooms = json['rooms'] as List? ?? [];
    final rawOpenings = json['openings'] as List? ?? [];
    final rawFixtures = json['fixtures'] as List? ?? [];
    final rawFurniture = json['furniture'] as List? ?? [];
    final rawScenes = json['scenes'] as List? ?? [];

    final cameraMap = json['camera'] as Map<String, dynamic>?;

    return House3DTwinLayout(
      name: json['name'] as String? ?? 'Home',
      wallHeight: (json['wallHeight'] as num?)?.toDouble() ?? 2.6,
      interiorWallHeight: (json['interiorWallHeight'] as num?)?.toDouble() ?? 1.25,
      outdoorTemp: (json['outdoorTemp'] as num?)?.toDouble() ?? 29.0,
      cameraAzimuth: (cameraMap?['azimuth'] as num?)?.toDouble() ?? 34.0,
      cameraElevation: (cameraMap?['elevation'] as num?)?.toDouble() ?? 47.0,
      rooms: rawRooms.map((r) => Room3DZone.fromJson(r as Map<String, dynamic>)).toList(),
      openings: rawOpenings.map((o) => Opening3D.fromJson(o as Map<String, dynamic>)).toList(),
      fixtures: rawFixtures.map((f) => Fixture3DNode.fromJson(f as Map<String, dynamic>)).toList(),
      furniture: rawFurniture.map((p) => Furniture3DProp.fromJson(p as Map<String, dynamic>)).toList(),
      scenes: rawScenes.isNotEmpty
          ? rawScenes.map((s) => HouseScene3D.fromJson(s as Map<String, dynamic>)).toList()
          : HouseScene3D.defaultScenes(),
    );
  }

  /// Parses House Control's native world-metric JSON format directly (`home.json`, `studio.json`).
  factory House3DTwinLayout.fromHouseControlJson(Map<String, dynamic> json) {
    final rawRooms = json['rooms'] as List? ?? [];
    double minX = 0, minZ = 0, maxX = 10.4, maxZ = 8.2;

    for (final r in rawRooms) {
      final rect = (r['rect'] as List?)?.map((e) => (e as num).toDouble()).toList();
      if (rect != null && rect.length >= 4) {
        if (rect[0] < minX) minX = rect[0];
        if (rect[1] < minZ) minZ = rect[1];
        if (rect[0] + rect[2] > maxX) maxX = rect[0] + rect[2];
        if (rect[1] + rect[3] > maxZ) maxZ = rect[1] + rect[3];
      }
    }

    final spanX = (maxX - minX > 0) ? (maxX - minX) : 10.4;
    final spanZ = (maxZ - minZ > 0) ? (maxZ - minZ) : 8.2;

    double normX(double x) => 0.04 + ((x - minX) / spanX) * 0.92;
    double normZ(double z) => 0.04 + ((z - minZ) / spanZ) * 0.92;
    double normW(double w) => (w / spanX) * 0.92;
    double normD(double d) => (d / spanZ) * 0.92;

    final parsedRooms = rawRooms.map((r) {
      final rect = (r['rect'] as List).map((e) => (e as num).toDouble()).toList();
      final floorType = FloorMaterialType.fromString(r['floor'] as String?);
      final rx = normX(rect[0]);
      final rz = normZ(rect[1]);
      final rw = normW(rect[2]);
      final rd = normD(rect[3]);

      return Room3DZone(
        id: r['id'] as String? ?? 'room',
        name: r['name'] as String? ?? 'Room',
        gridRect: Rect.fromLTWH(rx, rz, rw, rd),
        floorColor: floorType.color,
        floorType: floorType,
        cameraZoom: 1.85,
        cameraFocus: Offset(rx + rw / 2, rz + rd / 2),
      );
    }).toList();

    // Parse Openings
    final rawOpenings = json['openings'] as List? ?? [];
    final List<Opening3D> parsedOpenings = rawOpenings.isNotEmpty
        ? rawOpenings.map<Opening3D>((o) {
            final from = (o['from'] as List).map((e) => (e as num).toDouble()).toList();
            final to = (o['to'] as List).map((e) => (e as num).toDouble()).toList();
            return Opening3D(
              type: o['type'] as String? ?? 'door',
              from: Offset(normX(from[0]), normZ(from[1])),
              to: Offset(normX(to[0]), normZ(to[1])),
              sill: (o['sill'] as num?)?.toDouble() ?? 0.0,
              head: (o['head'] as num?)?.toDouble() ?? 2.1,
            );
          }).toList()
        : House3DTwinLayout.defaultApartment().openings;

    // Parse Furniture
    final rawFurniture = json['furniture'] as List? ?? [];
    final List<Furniture3DProp> parsedFurniture = rawFurniture.isNotEmpty
        ? rawFurniture.map((f) {
            final pos = (f['pos'] as List).map((e) => (e as num).toDouble()).toList();
            final size = (f['size'] as List?)?.map((e) => (e as num).toDouble()).toList();
            final fx = normX(pos[0]);
            final fz = normZ(pos[1]);

            String propRoom = 'living';
            for (final room in parsedRooms) {
              if (room.gridRect.contains(Offset(fx, fz))) {
                propRoom = room.id;
                break;
              }
            }

            final propType = f['type'] as String? ?? 'cube';
            double w = 0.12;
            double d = 0.10;
            double h = 0.08;

            if (size != null && size.length >= 2) {
              w = normW(size[0]);
              d = normD(size[1]);
            } else if (f['width'] != null) {
              w = normW((f['width'] as num).toDouble());
              d = w * 0.75;
            }

            if (f['height'] != null) {
              h = ((f['height'] as num).toDouble() / 2.6) * 0.35;
            } else if (propType == 'rug') {
              h = 0.005;
            } else if (propType == 'bed') {
              h = 0.10;
            } else if (propType == 'sofa') {
              h = 0.12;
            } else if (propType == 'plant') {
              h = 0.15;
            } else if (propType == 'bookshelf') {
              h = 0.22;
            }

            return Furniture3DProp(
              id: 'prop_${pos[0]}_${pos[1]}',
              type: propType,
              roomId: propRoom,
              x: fx,
              y: fz,
              width: w,
              depth: d,
              height: h,
              rotationDeg: (f['rot'] as num?)?.toDouble() ?? 0.0,
              colorHex: f['color'] as String?,
              chairs: (f['chairs'] as num?)?.toInt(),
              stools: (f['stools'] as num?)?.toInt(),
              isUpper: f['upper'] as bool? ?? false,
            );
          }).toList()
        : House3DTwinLayout.defaultApartment().furniture;

    // Parse Fixtures (Lights and ACs)
    final rawLights = json['lights'] as List? ?? [];
    final rawAcs = json['acs'] as List? ?? [];
    final List<Fixture3DNode> parsedFixtures = [];
    final wallHeight = (json['wallHeight'] as num?)?.toDouble() ?? 2.6;

    for (final l in rawLights) {
      final pos = (l['pos'] as List).map((e) => (e as num).toDouble()).toList();
      final y = (l['y'] as num?)?.toDouble() ?? 2.0;
      final caps = (l['capabilities'] as List?)?.map((e) => e.toString()).toList();
      parsedFixtures.add(
        Fixture3DNode(
          id: l['id'] as String? ?? 'light_${parsedFixtures.length}',
          label: l['name'] as String? ?? 'Light',
          fixtureType: 'ceiling_light',
          roomId: l['room'] as String? ?? 'living',
          x: normX(pos[0]),
          y: normZ(pos[1]),
          zHeight: (y / wallHeight).clamp(0.1, 1.0),
          capabilities: caps ?? const ['brightness'],
          colorHex: l['color'] as String?,
          intensity: (l['intensity'] as num?)?.toDouble(),
        ),
      );
    }

    for (final a in rawAcs) {
      final pos = (a['pos'] as List).map((e) => (e as num).toDouble()).toList();
      final y = (a['y'] as num?)?.toDouble() ?? 2.2;
      parsedFixtures.add(
        Fixture3DNode(
          id: a['id'] as String? ?? 'ac_${parsedFixtures.length}',
          label: a['name'] as String? ?? 'AC',
          fixtureType: 'wall_ac',
          roomId: a['room'] as String? ?? 'living',
          x: normX(pos[0]),
          y: normZ(pos[1]),
          zHeight: (y / wallHeight).clamp(0.1, 1.0),
          wall: a['wall'] as String?,
        ),
      );
    }

    // Parse Scenes
    final rawScenes = json['scenes'] as List? ?? [];
    final List<HouseScene3D> parsedScenes = rawScenes.isNotEmpty
        ? rawScenes.map((s) => HouseScene3D.fromJson(s as Map<String, dynamic>)).toList()
        : HouseScene3D.defaultScenes();

    final cameraMap = json['camera'] as Map<String, dynamic>?;

    return House3DTwinLayout(
      name: json['name'] as String? ?? 'House Control Home',
      wallHeight: wallHeight,
      interiorWallHeight: (json['interiorWallHeight'] as num?)?.toDouble() ?? 1.25,
      outdoorTemp: (json['outdoorTemp'] as num?)?.toDouble() ?? 29.0,
      cameraAzimuth: (cameraMap?['azimuth'] as num?)?.toDouble() ?? 34.0,
      cameraElevation: (cameraMap?['elevation'] as num?)?.toDouble() ?? 47.0,
      rooms: parsedRooms,
      fixtures: parsedFixtures.isNotEmpty ? parsedFixtures : House3DTwinLayout.defaultApartment().fixtures,
      furniture: parsedFurniture,
      openings: parsedOpenings,
      scenes: parsedScenes,
    );
  }

/// High-level stage of an Over-The-Air (OTA) update lifecycle
enum OtaStage {
  idle,
  checking,
  downloading,
  verifying,
  flashing,
  rebooting,
  completed,
  failed,
}

/// Progress metrics streamed during an active OTA update
class OtaProgress {
  final double progress; // 0.0 to 1.0
  final int bytesTransferred;
  final int totalBytes;
  final double speedMBps;
  final OtaStage stage;
  final String statusMessage;
  final String? errorMessage;

  const OtaProgress({
    this.progress = 0.0,
    this.bytesTransferred = 0,
    this.totalBytes = 0,
    this.speedMBps = 0.0,
    this.stage = OtaStage.idle,
    this.statusMessage = 'Ready',
    this.errorMessage,
  });

  bool get isInProgress =>
      stage == OtaStage.downloading ||
      stage == OtaStage.verifying ||
      stage == OtaStage.flashing ||
      stage == OtaStage.rebooting;

  bool get isCompleted => stage == OtaStage.completed;
  bool get isFailed => stage == OtaStage.failed;

  String get progressPercentage => '${(progress * 100).toStringAsFixed(1)}%';

  String get formattedTransferred {
    if (totalBytes <= 0) return '0 MB';
    final mbTransferred = (bytesTransferred / (1024 * 1024)).toStringAsFixed(1);
    final mbTotal = (totalBytes / (1024 * 1024)).toStringAsFixed(1);
    return '$mbTransferred / $mbTotal MB';
  }
}
